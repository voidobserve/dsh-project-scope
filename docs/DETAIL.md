# 单工程视图（Project scope）

把 DeepSeek Harness 的左侧边栏从「所有工程的会话堆在一起」改成「一次只看一个工程」：

- 侧边栏顶部是一个**工程切换器**，显示当前工程名与会话数，点开可以选其他工程（可输入过滤）。
- 下面**只列当前工程的会话**，固定的排最前，其余按最近活动时间排序。
- 切换工程时自动打开该工程**最近一条会话**；没有会话就停在空白新会话上。

## 工程按根目录归并

一个「工程」不是注册路径本身，而是**根目录**：

1. 如果某个已注册工作区的路径是另一个已注册工作区的上级目录，两者合并成一个工程（根目录取最上层那个）；
2. 否则，如果路径里带 `code` 段（例如 `<工程>\code\<工程>-xxx`），取 `code` 之上那层作为根目录。

所以 `<工程>` 与 `<工程>\code\project-xxx` 只会出现一次，它们的会话合并在同一个列表里。

## 会话行

| 能力 | 说明 |
|---|---|
| 状态 | 运行中显示转圈；等待批准 / 计划待审 / 等待回答显示黄点；已完成未查看显示蓝点 |
| 打开 | 点击行打开会话；已归档的行不可打开 |
| 固定 / 取消固定 | 悬停第一颗按钮，或 `...` 菜单 |
| 重命名 | `...` 菜单，回车保存、Esc 取消 |
| 分叉 | `...` 菜单，分叉后自动打开子会话 |
| 复制会话 ID | `...` 菜单 |
| **归档（隐藏）** | `...` 菜单；归档后该行从列表消失。会话仍在运行时会先询问是否停止再归档 |
| 取消归档 | 底部「显示已归档」打开后，归档行右侧出现取消归档按钮 |

侧边栏不显示滚动条，超长标题按省略号截断；内容仍可用滚轮滚动。

## 使用

1. 侧边栏顶部点工程名，选择要专注的工程。
2. 侧边栏只剩这个工程的会话；右侧对话区照常工作。

## 已知限制

- 接管期间，内置的工程浏览器（工作区树、拖拽排序、会话全文搜索框、悬浮卡片）由本插件替代；**停用本插件即立刻恢复内置界面，数据不受影响**。
- 归档是隐藏，不删除；取消归档需要先打开底部「显示已归档」。
- 工程归并按路径推断，不做磁盘扫描；注册路径之外的目录不会被发现。
